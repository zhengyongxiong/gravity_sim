# Gravity Simulator

Browser-based Newtonian N-body gravity simulator with WebGL rendering, deforming spacetime fabric, heatmap mode, collision fusion, presets, trails, selection stats, and spawn controls.

## Run

```bash
npm run dev
```

Open `http://127.0.0.1:5173`.

## Test

```bash
npm test
```

## Controls

- `WASD`: move camera
- `Space` / `Left Shift`: move up / down
- Mouse drag or pointer lock: look around
- Mouse wheel: zoom
- `O`: toggle camera/cursor mode
- `T`: trails
- `V`: fabric grid
- `Y`: heatmap
- `Esc`: pause/resume
- Cursor mode click: select body
